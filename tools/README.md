# ClawTalk Developer Tools

## PR Review Dashboard

Interactive dashboard showing all open PRs organized by merge risk level.

### Quick Start

```bash
# Generate live dashboard (requires GitHub token)
GITHUB_TOKEN=xxx bash tools/generate-dashboard.sh

# Or just open the static template
open tools/pr-dashboard.html
```

### Merge Strategy

1. **📝 Documentation** — Zero risk. Pure markdown/text. Merge immediately.
2. **🔧 Client Toolkits** — Self-contained scripts in `clients/`. No server changes needed.
3. **⚙️ Server Features** — New endpoints or behavior. Test before merge.

### Features

- Dark theme GitHub-style UI
- Risk-level categorization
- Mobile responsive
- Stats overview (total PRs, lines added, oldest PR age)
